# Python Installation Guide

To run Python programs, install a Python 3 interpreter. An editor such as Visual Studio Code can make writing and running programs more convenient.

## General Setup

1. Download Python 3 from [python.org](https://www.python.org/downloads/).
2. Run the installer and follow its instructions. On Windows, enable the option to add Python to `PATH` if it is offered.
3. Open a terminal and check the installation:

```text
python --version
```

On some systems, use:

```text
python3 --version
```

The command should print the installed Python 3 version.

## Run a Python File

Save code in a file ending with `.py`, for example `hello.py`:

```python
print("Hello, Python!")
```

In a terminal opened in the file's folder, run:

```text
python hello.py
```

If your system uses `python3`, run `python3 hello.py` instead.

## Remember

An editor helps you write code, while the Python interpreter executes it. The exact installation steps and terminal command can vary by operating system.
