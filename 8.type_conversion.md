# Type Conversion

Type conversion changes a value from one data type to another. Python provides built-in functions for common conversions.

## Common Conversions

```python
int("12")       # 12
float("3.5")    # 3.5
str(42)         # "42"
bool(1)         # True
```

Conversion can also be useful when working with user input:

```python
first_number = int(input("First number: "))
second_number = int(input("Second number: "))
print(first_number + second_number)
```

## Conversions to Watch

- `int("12")` works, but `int("12.5")` raises `ValueError`.
- `int(3.9)` truncates the fractional part and gives `3`; it does not round.
- `bool(0)` is `False`, and `bool(1)` is `True`. Empty strings are false-like; non-empty strings, including `"False"`, are true-like.
- Converting from a string only works when its contents are valid for the target type.

## Remember

Choose the conversion that matches the operation you need. Converting input to a number allows arithmetic; leaving it as text means operations such as `+` can join strings instead.
