# Printing Output

The `print()` function displays information in the output area or terminal.

## Basic Usage

```python
print("Hello, world!")
print(42)
```

Text must be written inside quotes. Numbers can be printed without quotes.

## Printing Multiple Values

`print()` separates multiple values with a space by default:

```python
name = "Mina"
age = 16
print("Name:", name, "Age:", age)
```

Output:

```text
Name: Mina Age: 16
```

## Useful Options

- `sep` changes the separator between values.
- `end` changes what is printed at the end. By default, `print()` ends with a newline.

```python
print("2026", "09", "30", sep="-")
print("Loading", end="...")
print("done")
```

## Remember

Use quotes for literal text, and use commas to pass multiple values to `print()`.
