# Data Types

A data type describes what kind of value an object represents and which operations make sense for it.

## Common Built-in Types

| Type | Meaning | Examples |
| --- | --- | --- |
| `int` | Whole number | `7`, `-12` |
| `float` | Number with a fractional part | `3.5`, `-0.25` |
| `str` | Text | `"Python"`, `'hello'` |
| `bool` | Truth value | `True`, `False` |

## Checking a Type

Use `type()` to inspect a value's type:

```python
print(type(7))        # <class 'int'>
print(type(3.5))      # <class 'float'>
print(type("hello")) # <class 'str'>
print(type(True))     # <class 'bool'>
```

## Remember

Text that looks like a number is still a string when it is quoted: `"7"` is a `str`, while `7` is an `int`. Python is dynamically typed, so a variable can refer to values of different types at different times.
