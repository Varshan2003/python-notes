# Operators

Operators perform calculations, compare values, or combine conditions.

## Arithmetic Operators

| Operator | Meaning | Example |
| --- | --- | --- |
| `+` | Addition | `7 + 2` gives `9` |
| `-` | Subtraction | `7 - 2` gives `5` |
| `*` | Multiplication | `7 * 2` gives `14` |
| `/` | Division (result is a float) | `7 / 2` gives `3.5` |
| `//` | Floor division | `7 // 2` gives `3` |
| `%` | Remainder | `7 % 2` gives `1` |
| `**` | Exponentiation | `7 ** 2` gives `49` |

## Comparison Operators

Comparisons produce a Boolean value (`True` or `False`):

```python
print(5 > 3)   # True
print(5 == 3)  # False
print(5 != 3)  # True
```

The comparison operators are `==`, `!=`, `<`, `>`, `<=`, and `>=`.

## Logical Operators

Use `and`, `or`, and `not` to combine or reverse Boolean expressions:

```python
age = 20
print(age >= 18 and age < 65)  # True
print(not (age < 18))          # True
```

## Assignment Operators

Assignment operators update a variable:

```python
score = 10
score += 5  # Same as score = score + 5
```

## Remember

`=` assigns a value; `==` checks whether two values are equal. Parentheses can make the intended order of operations clearer.
