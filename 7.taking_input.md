# Taking Input

Use `input()` to read a line of text from the user. It displays an optional prompt and returns the entered value as a string.

## Basic Usage

```python
name = input("Enter your name: ")
print("Hello,", name)
```

## Reading Numbers

Because `input()` returns a string, convert the result before doing arithmetic:

```python
age_text = input("Enter your age: ")
age = int(age_text)
print("Next year you will be", age + 1)
```

For decimal values, use `float()` instead of `int()`.

## Remember

If the user enters text that cannot be converted to the requested number type, Python raises a `ValueError`. Input validation can be added later to handle that case.
