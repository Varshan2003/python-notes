# Variables

A variable is a name that refers to a value. Variables let a program store and reuse information.

## Creating and Using Variables

Use `=` to assign a value to a variable:

```python
name = "Ari"
score = 95
print(name)
print(score)
```

Here, `name` refers to the string `"Ari"`, and `score` refers to the integer `95`.

## Naming Rules

- Names can contain letters, digits, and underscores.
- A name cannot start with a digit.
- Names are case-sensitive: `score` and `Score` are different names.
- Do not use Python keywords such as `if` or `for` as variable names.
- Prefer descriptive names such as `total_price` over unclear names.

## Reassignment

A variable can be assigned a new value:

```python
count = 1
count = count + 1
print(count)  # 2
```

## Remember

The `=` symbol assigns a value; it does not mean “is equal to” as it does in ordinary math. Equality comparisons use `==`.
